# Bob's Universe

A prototype for the Robert A.F. Thurman Archive: the *Bob's Buddhism* Pop-up Series (Tibet House US, 2026) as a linked web of people, concepts, texts, places, stories and timestamped moments. It has a 3D view and a flat map, and each moment links into the recording at its start time.

Built from a SQLite catalogue whose entities follow the archive's data model (Item, Agent, Subject/Place/Event, Rights). Session 1 (Series Introduction, 13 Oct 2026) is catalogued; sessions 2–6 will be added as they happen.

Source material: Tibet House US public event recording, with Google Drive's automatic transcript as a convenience copy. Images are hot-linked with their credits; most are openly licensed (Wikimedia Commons, The Met Open Access).

Prepared by Regina Flores Mir.
